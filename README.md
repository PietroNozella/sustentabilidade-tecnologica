# Sustentabilidade tecnológica

Guia didático a partir do panfleto *Sustentabilidade Tecnológica*, com a paleta verde e creme do material original. Explica ESG, lixo eletrônico, energia, vida útil, riscos e descarte em Mogi das Cruzes. As fontes complementares estão identificadas na página.

HTML e CSS, sem dependências, JavaScript, coleta de dados ou etapa de build. As perguntas usam o elemento nativo `details`.

Para visualizar localmente, sirva esta pasta com `python -m http.server 4173` e abra `http://localhost:4173`.

Publicação: GitHub Pages a partir da raiz da branch `main`.
